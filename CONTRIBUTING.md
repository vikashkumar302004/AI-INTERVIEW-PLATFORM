# Contributing to AI Interview Platform

Thanks for helping improve the project. Contributions should be small, focused, and easy to review.

## Development workflow

1. Create a branch from `main` using a descriptive name such as `feat/interview-session` or `fix/feedback-score`.
2. Keep each commit focused on one logical change.
3. Test the affected behavior locally.
4. Open a pull request that explains what changed, why it was needed, and how it was verified.

## Commit style

Use a short conventional prefix when possible:

- `feat:` for a new capability
- `fix:` for a bug fix
- `docs:` for documentation
- `test:` for test coverage
- `refactor:` for an internal improvement

## Pull request checklist

- [ ] The change has a clear purpose and limited scope.
- [ ] Documentation is updated where required.
- [ ] No credentials, tokens, or private data are committed.
- [ ] New behavior includes suitable tests when applicable.
- [ ] The pull request describes the verification performed.

## Reporting security issues

Please do not disclose vulnerabilities in public issues. Share security reports privately with the repository owner, including reproduction steps and potential impact.
